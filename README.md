Tic Tac Toe — Neon Edition

A modern, responsive Tic Tac Toe game built with pure HTML, CSS, and JavaScript. It features a futuristic neon interface, animated game board, score tracking, CPU opponent, keyboard controls, and animated result screens.

✨ Features

🎮 Player vs CPU gameplay
🤖 CPU opponent with win and block logic
🏆 Win, lose, and draw detection
📊 Score tracking for Player X, CPU O, and draws
🔄 New Game button
🗑️ Reset Score button
⌨️ Keyboard support using keys 1–9
✨ Neon/glassmorphism UI
🎨 Smooth animations and hover effects
📱 Responsive design for mobile devices
🏅 Animated winning-cell highlight
🪟 Result modal for win, loss, and draw

🛠️ Technologies Used

HTML5 — Game structure
CSS3 — Styling, responsive layout, gradients, animations, and effects
JavaScript — Game logic, CPU moves, scoring, and interactions
Google Fonts — Space Grotesk
